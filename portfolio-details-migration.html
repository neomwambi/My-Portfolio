Standard Bank Insurance Book Migration , 5 Countries

As lead developer across all five migration projects at MobiLife, I was responsible for the full technical delivery of migrating Standard Bank's life and funeral insurance books into the MobiLife system , covering South Africa, Zimbabwe, Malawi, Eswatini, and Botswana. Each country was treated as its own independent project with its own data structure, timeline, and stakeholder team.

The process began with weekly column mapping sessions with each country's team, translating their system's data structure into MobiLife's schema. Data was delivered in Excel format, and I developed all the Python and MySQL scripts required to read the data from the files and insert it accurately across multiple related database tables, handling data type conversions, referential integrity, and edge cases specific to each country's policy book.

Each migration followed a two-phase approach: a full test environment run for quality assurance and stakeholder sign-off, followed by the production migration on go-live day. Across all five projects, zero data loss was recorded and all migrations were delivered successfully.
