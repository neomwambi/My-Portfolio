Benefits Update Automation Tool

Working in the insurance industry, a recurring task involved receiving Excel files from tenants requesting updates to the date of birth and ID number fields on specific benefits records in the database. The previous process required manually searching for each benefit and writing individual SQL UPDATE scripts by hand; slow, repetitive, and risky.

To solve this, I built an internal web-based frontend that removes the manual effort entirely. The user simply uploads the Excel file through the interface. In the background, a Python script reads the file, locates all the relevant benefit records in the database, and automatically generates the correct SQL UPDATE scripts for each one. The scripts are returned to the user for review, ready to be sent to the Head of Department for approval before being executed in the production database. This tool eliminated manual scripting time, reduced the risk of human error, and introduced a proper approval step into the workflow.
