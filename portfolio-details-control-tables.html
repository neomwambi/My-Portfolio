Control Tables Power BI Dashboard

MobiLife operates both a production database and a data warehouse, with several clients having direct access to the data warehouse for their own reporting and operations. It is critical that both environments remain fully in sync; any discrepancy in record counts means clients could be working with incomplete or missing data without knowing it.

I built this Power BI dashboard as an internal data integrity monitoring tool. It compares record counts across key tables between the production MySQL database and the data warehouse, providing an immediate view of whether the two environments are aligned. Any mismatch is flagged, prompting investigation before it affects downstream clients. Data is pulled using MySQL scripts that query both environments and feed the comparison logic directly into the dashboard. This tool has become essential to the team's day-to-day data governance process.
